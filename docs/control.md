# 자동 제어와 설정

## 사용자 흐름

웹을 열면 저장된 설정을 불러온 뒤 빛 민감도, 소리 민감도, 완화할 때 사용할 빛을 선택합니다. 저장과 자동 시작이 성공하면 홈으로 이동합니다. 평소 밝기·색온도·팬 세기와 허용 범위는 보호자 설정에서 관리합니다. 저장된 설정이 빌드 기본값보다 우선합니다.

| 모드 | 동작 |
| --- | --- |
| `AUTO` | 주변 변화와 개인 설정에 따라 조명·팬을 함께 조절 |
| `MANUAL` | 직접 선택한 출력을 유지 |
| `OVERRIDE` | 일정 시간 사용한 뒤 자동 모드로 전환 |
| `SAFE` | 조명·팬 정지. 사용자 화면에서는 선택 불가 |

보호자의 직접 제어는 아이 요청을 취소하고 수동 모드로 전환합니다. ‘잠시 사용’은 1분~24시간을 지정하며 기본 15분입니다.

## 환경 점수와 학습

센서는 200 ms, 알고리즘은 250 ms 주기로 처리합니다. 마이크는 16 kHz mono의 100 ms 창에서 정규화 PCM RMS를 구합니다. API의 `soundEnergy`는 이 상대 진폭이며 dB/SPL이 아닙니다.

각 채널의 증가량을 `max(0, 측정값−중앙값) / max(MAD, 최소 폭)`으로 계산하고 민감도를 곱해 합산합니다. 최소 폭은 빛 2 lx, 소리 RMS 0.0025이며 표시 점수는 0~4입니다. 화면 문구는 1.4와 2.8에서 구분합니다. 이 값은 환경 변화 지표이며 불편함이나 의학적 상태를 판정하지 않습니다.

학습 창은 수락한 새 표본 31개입니다. AUTO의 평소 출력이 안정된 상태에서 가중 절대 변화 합이 0.7 이하일 때만 갱신합니다. 수동·완화·복귀, 출력 전환·오류, 중복·오래된 입력은 학습하지 않습니다. 출력 안정화 대기는 최소 500 ms입니다. 재부팅하면 현재 환경으로 다시 학습합니다.

평소 밝기·색온도 변경은 빛 기준, 평소 팬 세기 변경은 소리 기준을 새 출력이 안정된 뒤 다시 잡습니다. 갱신 대기 중인 채널은 AUTO 점수 기여를 보류합니다. 센서값에는 자체 조명과 팬의 영향도 포함됩니다.

## 완화와 복귀

빛·소리 합산 점수 1.4 이상이 진입 시간 동안 지속되면 조명과 팬을 함께 낮춥니다. 최소 유지 시간과 0.7 이하의 복귀 확인 조건을 만족하면 평소 출력으로 서서히 돌아갑니다. 복귀 중 중간 점수에서는 출력을 유지하고, 높은 점수가 지속되면 마지막 안전 출력으로 돌아갑니다. 복귀 실패 후에는 같은 출력에서 환경 개선이 확인되어야 다시 시도합니다.

| 항목 | 기본 시연 빌드 | 일반 빌드 (`DEMO_DEFAULTS=OFF`) |
| --- | --- | --- |
| 평소 밝기 / 팬 | 100% / 100% | 60% / 60% |
| 밝기 상한 / 완화 하한 | 100% / 30% | 80% / 30% |
| 평소 / 완화 색온도 | 250 / 454 mired | 동일 |
| 완화 팬 세기 | 0% | 20% |
| 진입 확인 | 3초 | 0.75초 |
| 자동 완화 | 목표까지 5초 | 점수에 비례해 점진 조절 |
| 최소 유지 | 두 출력 도달 후 5초 | 완화 시작 후 30분 |
| 복귀 확인 | 3초, 최소 유지와 함께 확인 | 최소 유지 후 3초 |
| 자동 복귀 | 안정된 조건에서 5초 | 500 ms마다 최대 2%p |
| 아이 요청 유지 | 목표 도달 후 5초 | 목표 도달 후 30분 |
| 재실 자동화 / 유지 | 꺼짐 / 30초 | 꺼짐 / 15분 |

설정값은 제어용 공학 값이며 임상 기준이 아닙니다. 센서·출력 오류와 안정화 대기로 실제 전환 시간은 길어질 수 있습니다. 색온도는 `K = 1,000,000 / mired`로 표시하며 WS2812B의 백색 혼합 설정입니다.

팬 상한이 18% 미만이면 팬을 끕니다. 그 외 0이 아닌 요청은 최소 18%로 적용합니다. 정지 후 기동 시에는 350 ms 동안 100%로 구동하므로 설정 상한을 일시적으로 넘을 수 있습니다. PWM 적용 성공은 실제 회전·풍량 측정이 아닙니다.

## 아이 요청과 움직임

아이 화면은 밝음·어두움·시끄러움·조용함 네 요청을 제공합니다. 펌웨어가 현재 출력과 보호자 범위에 맞춰 함께 처리합니다. 밝기·소음 감소 요청은 꺼진 조명을 켜거나 낮은 출력을 높이지 않습니다.

시연 빌드는 밝음 요청을 밝기 하한까지, 시끄러움 요청을 밝기 하한과 팬 완화 목표까지 낮춥니다. 일반 빌드의 조절 폭은 30%p입니다. 어두움은 조명을, 조용함은 팬을 높입니다. 요청은 5초간 전환하고 유지 시간 후 AUTO로 넘어가며, 환경 조건을 확인해 복귀합니다. 더 조절할 수 없으면 변경하지 않습니다.

재실 자동화가 켜져 있으면 마지막 움직임 이후 유지 시간이 지나면 조명·팬을 끄고, 움직임을 감지하면 자동 제어를 재개합니다. 꺼져 있으면 움직임이 없어도 자동 제어합니다. 직접 끈 수동 출력은 움직임으로 켜지지 않습니다. PIR은 움직임을 감지하므로 가만히 있는 사람을 놓칠 수 있습니다.

## 고정 비교 기준

`src/demo/environment_samples.h`의 기본값은 `Enabled=false`, 표본 수 0입니다. 고정 기준이 필요한 시연에서는 평소 출력 100%·250 mired·팬 100%에서 측정한 lux/RMS 31쌍을 두 배열에 넣고 `count=31`, `Enabled=true`로 빌드합니다.

시연 빌드에서 저장된 평소 출력이 측정 조건과 일치할 때만 적용합니다. 고정 중 평소 출력을 바꾸면 자동 학습으로 전환합니다. 일반 빌드는 고정 표본을 사용하지 않습니다. 적용 상태는 `/api/diagnostics`의 `demo.baselineFrozen`으로 확인합니다.
