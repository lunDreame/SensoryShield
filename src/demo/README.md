# 현장 리허설 설정

기본 시연 빌드는 실제 센서·조명·팬·Matter 연결을 사용한다. 화면 개발용 Mock은 보드에 포함하지 않는다. 아래 값은 시연용 공학 설정이며 임상적으로 검증된 진정 시간이 아니다.

| 항목 | 시연 | 실사용 빌드의 시작 설정 |
| --- | --- | --- |
| 평소 조명 / 팬 | 100% / 100% | 60% / 60% |
| 밝기 상한 / 완화 하한 | 100% / 30% | 80% / 30% |
| 평소 / 따뜻한 완화 색온도 | 250 / 454 mired (약 4,000 / 2,200 K) | 동일, 저장한 개인 선택 우선 |
| 완화 팬 목표 | 0% (꺼짐) | 20% |
| 자동 진입 | 합산 점수 1.4 이상 3초 연속 | 1.4 이상 0.75초 연속 |
| 자동 완화 | 설정한 완화 목표까지 5초 | 점수 비례 밝기 목표, 기존 점진 제어 |
| 최소 유지 | 두 출력 적용값이 목표에 도달한 뒤 5초 | 완화 시작 후 30분 |
| 복귀 확인 | 0.7 이하 3초, 최소 유지와 겹쳐 확인 | 최소 유지 후 0.7 이하 3초 |
| 자동 복귀 | 안정적이면 5초 | 기존 2%p 단위 복귀와 출력 안정 확인 |
| 아이 요청 감소 폭 | 조명 하한까지, 시끄러워요는 팬도 완화 목표까지 | 현재보다 30%p, 보호자 범위 안에서 조절 |
| 아이 요청 시간 | 5초 조절 → 도달 후 5초 유지 → 조건 충족 시 5초 복귀 | 5초 조절 → 도달 후 30분 유지 → 조건 충족 시 5초 복귀 |
| 재실 자동 종료 | 기본 꺼짐, 켜면 30초 | 기본 꺼짐, 켜면 15분 |

아이 요청 유지가 끝나면 AUTO로 전환하지만 자극이 남아 있으면 평소 출력으로 강제 복귀하지 않는다. 복귀 중 0.7을 넘으면 정지하고, 1.4 이상이 지속되면 다시 완화한다. 복귀 실패 이후에는 환경 개선을 확인하고 재시도한다. 센서·제어 주기(200/250ms)와 출력 반영 지연으로 실제 소요 시간에는 작은 차이가 있다. 출력 오류·팬 기동 중에는 도달로 보지 않는다. 보호자 수동 명령은 아이 요청을 취소한다.

## 기존 보드 설정
평소 빛의 기본값은 4,000 K(250 mired), 따뜻한 완화 빛의 기본값은 약 2,200 K(454 mired)다. 조명 초기 상태도 평소 색온도를 사용한다. 저장된 수동 색상과 보호자가 선택한 평소·완화 색온도는 유지한다.

저장된 보호자 설정이 기본값보다 우선한다. 업데이트만으로 기존 60%·3초가 바뀌지 않으므로 **웹 설정에서 위 시연 값과 원하는 완화 색을 저장하고 AUTO로 전환**한다. 설정 변경을 위해 Matter 연결까지 지우는 공장 초기화는 필요하지 않다.

## 내일 실측 표본 입력
1. 발표처럼 사람이 말하는 공간에서 보드를 배치한다. 보호자 수동 제어로 조명 100%·250 mired·팬 100%를 안정적으로 유지한다.
2. 실제 조도 lux와 sound.energy(웹의 soundEnergy, 0~1 PCM RMS이며 dB가 아님) 31쌍을 수집한다. 센서 오류·팬 기동·손전등·소음 영상 입력 중의 표본은 제외한다.
3. 같은 폴더의 environment_samples.h에 count=31, lux 배열 31개, sound 배열 31개를 넣고 Enabled=true로 설정한다. 같은 배열 위치끼리 같은 시점의 표본이다.
4. 다시 빌드·업로드하고 AUTO로 전환한다. 기기 상태 화면 또는 /api/diagnostics에서 demo.enabled=true, demo.baselineFrozen=true를 확인한다.
5. 손전등 하나와 유튜브 소음 영상으로 각각 입력 → 공동 완화 → 입력 제거 → 복귀를 3회 확인한다. 성공한 배치·거리·영상 음량을 본 시연에 유지한다.

현재는 Enabled=false, count=0으로 비워뒀으므로 자동 학습한다. 유효한 표본을 넣은 시연 빌드에서만 기준 갱신을 정지하며, 실시간 측정·점수 계산·제어는 계속한다. 저장된 평소 출력이 표본을 측정한 출력과 다르면 고정을 적용하지 않는다. 고정 중 평소 출력 설정을 바꾸면 고정을 해제한다. 실사용 빌드(SENSORYSHIELD_DEMO_DEFAULTS=OFF bash scripts/build.sh)는 표본 활성화 여부와 관계없이 자동 학습한다.
